The welcome tour helps you set up the Windows app. Choose whether this computer starts a network, joins one, or lends its power as a host.

## Follow the welcome tour

1. Choose whether to start a new Martlet network, join one, or set up this PC as a host. To join, select a computer Martlet finds, or enter its address and pairing code. See [Setting Up a Host](Setting-Up-a-Host).
2. Review the hardware Martlet found on this computer.
3. Answer questions about games, online services, and reply speed.
4. Review the suggested setup. Martlet shows where its jobs will run.
5. Choose **Use these suggestions** and confirm the setup before Martlet installs or downloads the selected items.

The tour can ask you for an online-service key when the suggestion needs one. You can skip the key and continue. See [Thinking](Thinking) for model choices.

## Use Home

Home shows setup steps and health checks. Its **Get started** card guides you through:

1. Set up where Martlet runs.
2. Choose who Martlet is.
3. Talk with Martlet.

Choose **Recommended setup** to review the available setup plan. You can also set up each job from its Companion page. See [Home](Home), [Thinking](Thinking), and [Talking to Martlet](Talking-to-Martlet).

More detail: [The welcome wizard](https://github.com/throndir2/Martlet/blob/main/docs/WELCOME_WIZARD.md), [Recommended setups](https://github.com/throndir2/Martlet/blob/main/docs/RECOMMENDED_SETUPS.md).
