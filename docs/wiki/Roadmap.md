# Roadmap

This page separates shipped Windows functionality from plans.

## Shipped Windows / host work

The current docs cover the Windows companion, Linux/Windows Docker hosts, conversation, voice, vision, memory, tools, Live2D/VRM overlay, Home Assistant, Discord, messaging, Pictures, Singing, Creations, Martlet network, sync and failover. Check each feature page for qualification limits and NOT RUN items.

## macOS plan

Planned, not built. Direction: native SwiftUI/AppKit app, companion window, menu bar item, **Lend this Mac** host mode, Apple speech/voices/Intelligence where available, Ollama/whisper.cpp/MLX on Apple silicon, ScreenCaptureKit and transparent character panel. Every Mac result is NOT RUN.

## iOS/iPadOS plan

Planned, not built. Direction: native SwiftUI app, gateway protocol seam, Apple SpeechAnalyzer/Foundation Models, ReplayKit screen broadcast, Picture-in-Picture character experiment, free Apple ID sideloading limitations. Every iPhone/iPad result is NOT RUN.

## Android plan

Planned, not built. Direction: Kotlin + Jetpack Compose, foreground hosting service, Android on-device speech/voices, LiteRT/llama.cpp/Gemini Nano where allowed, MediaProjection, overlay character, old phone satellite/camera uses and signed APK with free key. Every Android result is NOT RUN.

## Deep research plan

Planned background job: plan subquestions, search/fetch safely, compress notes, reflect, write a cited report and save it as a `report` creation. Backends include SearXNG, Ollama web search, Tavily, Brave, Exa and MCP search tools; provider-native deep research is paid/opt-in.

## Delivery rules

Local validation only, no Copilot Cloud, no remote validation CI, Actions only for release build, no silent cloud fallback, planned choices not offered as shipped.
