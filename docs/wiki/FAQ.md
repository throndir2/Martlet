# FAQ

## What is Martlet?

A Windows desktop AI companion that talks, listens, watches your screen when allowed and appears as a desktop character.

## What Windows versions work?

Windows 10 2004+ or Windows 11, x64.

## Is the installer signed?

No. Public installers are unsigned normal releases. Windows may warn about an unknown publisher.

## Does Martlet need a GPU?

No. A basic setup can use cloud Thinking and typed text. A GPU helps local Thinking, cloned voices, Singing, Pictures and Audio2Face.

## Does Martlet listen on launch?

No. Listening starts only with **Start listening** or push-to-talk.

## Does Vision save screenshots?

No. Screenshots are in memory only. Martlet can keep text notes about what it saw in conversation context.

## Where are keys stored?

Windows Credential Manager.

## Can another PC do the heavy work?

Yes. Pair a host and use Devices to choose which computer does each job.

## Can Martlet control smart home devices?

Yes, through Home Assistant. Sensitive devices are blocked or ask every time depending on settings.

## Can I add my own character or voice?

Yes. Add Live2D/VRM characters in **Companion › Character** and voices in **Companion › Voice › Voices**. Only use voices/models you have rights to use.

## What is MCP?

Model Context Protocol. Martlet can use MCP servers as tools, and developers can use Martlet's local MCP server for validation.
