Martlet voice recognition: third-party components and notices
================================================================

Voice recognition (Companion > People) is part of Martlet. These components ship
unmodified in Martlet's Desktop folder. Martlet binds the sherpa-onnx C API with
its own P/Invoke code (Martlet.Sherpa); no managed sherpa-onnx package is used.
