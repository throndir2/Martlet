Martlet Windows dependency inventory

Martlet original code/assets: see the bundled LICENSE for the release-specific
binary-use terms. Third-party dependencies retain their own licenses.

Bundled runtime: .NET 10.0.12 win-x64; SDK 10.0.401 is a build tool, not shipped.
Desktop, Doctor and the private Desktop\AvatarRenderer host each retain their
own complete ordinary self-contained files.
CoreCLR/hostfxr/hostpolicy and WindowsDesktop native binaries (including WPF
graphics, Direct3D compiler and vcruntime*_cor3) come from the pinned Microsoft
runtime NuGet packages, not from the developer's Windows installation.
Windows OS APIs/drivers remain OS prerequisites, not redistributed libraries.

Desktop\LICENSE.txt and THIRD-PARTY-NOTICES.txt: unmodified Microsoft.NETCore.App.
Doctor\LICENSE.txt and THIRD-PARTY-NOTICES.txt: the same runtime notices.
Desktop\AvatarRenderer\LICENSE.txt and THIRD-PARTY-NOTICES.txt: the same notices.
notices\Microsoft.WindowsDesktop.App\LICENSE.txt: runtime package's license.
notices\WPF-THIRD-PARTY-NOTICES.txt and WinForms-THIRD-PARTY-NOTICES.txt:
upstream notices from the matching v10.0.12 source tags, checksum pinned.
The complete runtime notice lists are retained, not reduced to just this summary.

Both native entry points include Martlet.Core, Diagnostics
and the Windows Audio target. Desktop additionally includes Martlet.Conversation,
Martlet.Providers and Martlet.Participation for V04b explicit typed / push-to-talk
app integration. These authored BCL-only libraries add no NuGet package, native
binary, model, voice recording or provider SDK. OpenAI is a configured remote
API destination, not a redistributed library; no API call occurs on launch.
Doctor retains its offline graph: none of these three assemblies is bundled in
Doctor. Desktop additionally includes Martlet.Support for V06b local
troubleshooting metadata recording, immutable preview and explicitly approved
local ZIP export. This authored BCL-only library adds no NuGet package, native
binary, provider SDK or network/upload channel. Its Diagnostics dependency
reuses the existing Core graph; no duplicate collector
or redactor is redistributed. Doctor shares authored Diagnostics help only
and does not depend on or bundle Martlet.Support.

NAudio.Wasapi 3.1.0, NAudio.Core 3.1.0 and System.Numerics.Tensors 9.0.0
are the existing centrally pinned audio dependencies, not newly upgraded pins.
Their raw NuGet archives and published managed DLL bytes are checked against
toolchain.json. Raw signed-archive SHA-512 differs from NuGet's lock contentHash;
both are preserved for their respective purposes.

For Add a voice's Ogg recordings (.ogg, .oga, .opus), the Windows Audio target
also brings, to both Desktop and Doctor, NVorbis 0.10.5 (NVorbis.dll,
lib/netstandard2.0; MIT, Copyright (c) 2020 Andrew Ward), a managed Vorbis
decoder, and Concentus 2.2.2 (Concentus.dll, lib/net8.0), a managed C# port of
the Opus codec (BSD-3-Clause; Skype Limited, Xiph.Org Foundation, CSIRO,
Microsoft, Jean-Marc Valin, Gregory Maxwell, Mark Borgerding, Timothy B.
Terriberry, Logan Stromberg and others). Neither has a NuGet dependency on .NET
10. Both archives and both DLLs are pinned in toolchain.json;
notices\NVorbis-LICENSE.txt and Concentus-LICENSE.txt are the complete license
files from each archive. Martlet uses only Concentus' managed decoder and never
loads a native opus.dll, so none is redistributed. They decode only files the
owner chooses on this PC; only the resulting PCM WAV is stored or shared, and
Doctor never decodes them.

Desktop also includes SSH.NET 2024.1.0 (Renci.SshNet.dll, lib/net8.0, no NuGet
dependencies), the SSH client for Martlet hosts' in-app SSH runner (HostShell). Its archive
and published DLL bytes are pinned in toolchain.json; notices\SSH.NET-LICENSE.txt is the
complete MIT license from the package's declared source commit
a5531521952b2814ef5ee11361e078ea3d92eb08. Its two NuGet advisories (GHSA-q939-rpr3-3284,
GHSA-mggc-4xg6-vcxf) affect only ScpClient, which Martlet never uses.

Desktop also includes Martlet.EchoCancellation (authored) and, for Companion >
Listening > Reduce echo from my speakers, WebRTC's acoustic echo canceller:
SoundFlow.Extensions.WebRtc.Apm 1.4.0 (its managed binding
SoundFlow.Extensions.WebRtc.Apm.dll, lib/net8.0, and the unmodified native
runtimes/win-x64/native/webrtc-apm.dll) and its dependency SoundFlow 1.4.0
(SoundFlow.dll, lib/net8.0; MIT, Copyright (c) 2025 LSXPrime). Both archives
and both managed DLLs are pinned in toolchain.json; webrtc-apm.dll is the
archive's own file, checked as x64. SoundFlow's own audio engine is never used:
Desktop excludes its miniaudio native libraries, so none is redistributed.
notices\SoundFlow-LICENSE.txt and SoundFlow-THIRD-PARTY-NOTICES.txt are the
complete files from the SoundFlow archive (identical in both archives; the
latter also names libraries Martlet doesn't ship). webrtc-apm.dll is built from
PulseAudio's webrtc-audio-processing 2.1 and statically contains WebRTC
(BSD-3-Clause, with Google's patent grant), Abseil (Apache-2.0), PFFFT
(FFTPACK license), RNNoise (BSD-3-Clause), Ooura FFT and spl_sqrt_floor
(public domain); notices\WebRTC-APM-NOTICES.txt carries each complete license
and where it came from. It imports only KERNEL32, ucrtbase and WINMM from
Windows. While the microphone listens it reads what the output plays (WASAPI
loopback, authored code in Martlet.Audio) only to subtract it, in memory; that
audio is never kept, logged or sent.

Desktop also includes Martlet.Credentials.Windows, authored BCL/PInvoke code
for explicitly scoped Windows Credential Manager actions. No additional NuGet
package or native binary is redistributed; advapi32 remains a Windows OS API.
Doctor does not reference this vault assembly or resolve credentials.

Voice ID (optional, local only): Martlet.Desktop embeds Resemblyzer's pretrained
GE2E voice encoder weights (resemble-ai/Resemblyzer, commit
15d828edebe06bc72b9cabc8ef8ca5ab2cb457ce, resemblyzer/pretrained.pt, SHA-256
39373b86598fa3da9fcddee6142382efe09777e8d37dc9c0561f41f0070f134e), Copyright
2019 Resemble.AI, Apache License 2.0. Modification: the checkpoint was converted by
scripts\Convert-SpeakerEncoder.py into a flat float32 file with the two LSTM
bias vectors pre-summed; weights are otherwise unchanged. Inference is authored
managed code in Martlet.Audio (no NuGet package, native runtime or GPU).
notices\Resemblyzer-LICENSE.txt: the complete upstream Apache-2.0 license from
that commit. The encoder was trained upstream on LibriSpeech and VoxCeleb; no
recording or training audio is redistributed. Hands-free voice activity is an
authored energy detector and adds no model.

BundledVoices) that a new voice list begins with and the voice engines copy a

readings of Anne of Green Gables (WoollyBee, CC0; Annie Coleman Rothenberg, public
domain), each as read and with pitch and formants raised (marked), LJ Speech 1.1
(public domain LibriVox audio) and two CMU ARCTIC speakers (slt, bdl; Carnegie
Mellon University, free for any use including commercial,
notice retained, modifications marked). scripts\Build-F5BundledVoices.py cut,
level and wrote them from pinned upstream files. notices\F5-Voices-NOTICES.txt
lists each source, its SHA-256, transcript and the modifications, with the CMU
ARCTIC COPYING text unchanged. LJ Speech's reader and the LibriVox and CMU
ARCTIC speakers do not say or endorse anything Martlet speaks in their voices.
Earlier versions bundled F5-TTS's English example clip; it is no longer included.

Voice recognition (bundled, on by default): Desktop includes authored
Martlet.Sherpa and Martlet.Home (BCL-only) and ships, unmodified, in its Desktop
folder:
- sherpa-onnx 1.13.8 (Apache-2.0, Xiaomi Corporation / Next-gen Kaldi) and
  ONNX Runtime 1.28.2 (MIT, Microsoft): sherpa-onnx-c-api.dll and onnxruntime.dll
  from the NuGet package org.k2fsa.sherpa.onnx.runtime.win-x64 1.13.8 (pinned in
  toolchain.json). notices\sherpa-onnx-LICENSE.txt, notices\onnxruntime-
  LICENSE.txt and notices\onnxruntime-ThirdPartyNotices.txt carry the full
  upstream texts.
- voice-recognition\wespeaker_en_voxceleb_resnet34_LM.onnx: WeSpeaker ResNet34-LM
  speaker embedding model (CC BY 4.0, WeSpeaker authors; sherpa-onnx ONNX export).
- voice-recognition\pyannote-segmentation-3-0\model.onnx and its LICENSE:
  pyannote segmentation 3.0 ONNX export (MIT, CNRS).
The Desktop build downloads the models once and keeps each only if it matches
the SHA-256 pinned in Martlet.Desktop.csproj and toolchain.json (voiceModels);
packaging checks the shipped bytes again. notices\Voice-Recognition-NOTICES.txt
gives attribution, sources and hashes. Martlet binds the sherpa-onnx C API with
authored P/Invoke code; no managed sherpa-onnx package is redistributed.
