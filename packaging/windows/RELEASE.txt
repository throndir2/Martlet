MARTLET FOR WINDOWS

The installer is not code-signed, so Windows may show an unknown-publisher
warning. A checksum from the GitHub release page detects download corruption.
Do not disable system security protections to install Martlet.

Requires 64-bit (x64) Windows 10 version 2004 (build 19041) or newer, including
any current Windows 11. Mainly tested on Windows 11 25H2.
This per-user installer provides a self-contained Desktop app, a Doctor CLI,
dependency notices, a prerequisites tool, and an uninstaller. Setup asks no
questions and installs nothing else. When Martlet first starts, its welcome
tour asks what this PC is for, offers anything missing here (the WebView2
runtime for the desktop character, microphone access, Windows speech, Ollama
for a local LLM, or WSL 2 and Docker Desktop for GPU roles) and can recommend
a setup for your computers. Only items you tick download, from their
publishers, and keep their own license terms; Windows features ask for
administrator approval separately. Run "Martlet prerequisites" from the Start
menu to check or add them later. No API calls,
microphone capture, model download, startup task, or automatic installation
occurs merely by launching Martlet. If you opt in, Martlet checks GitHub for
updates while it runs and can install them for you (Settings > App updates);
real provider use requires explicit configuration
and per-action consent and may incur charges.

An in-app update closes
Martlet, runs the newer installer and starts Martlet again; to update by hand,
close Martlet before running a newer installer.
